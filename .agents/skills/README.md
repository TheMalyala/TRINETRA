# Workspace Skills

This directory contains workspace-specific skills for Antigravity:
- `ocr-lab-parser`: Prompts and regex rules for parsing multi-line lab observation tables.
- `fhir-mapping`: Mapping tables between Trinetra internal models and ABDM/FHIR R4 resources.
- `hash-chain`: Utilities for verifying and creating SHA-256 Merkle audit chains.
