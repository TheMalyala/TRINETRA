# AI Safety & Guardrail Rules

1. **Role of Netra**:
   - The AI explains, summarizes, translates jargon, and prepares questions for doctors.
   - It NEVER diagnoses, prescribes, suggests changing dosage, or orders medication changes.
2. **Deterministic Grounding**:
   - Numbers and trend labels (improving/stable/worsening) must be generated by the pure Kotlin `analytics-engine`, never by LLMs.
   - AI output validator rejects any response where numerical values differ from input facts.
3. **Citations Mandatory**:
   - Every patient-specific fact must cite an observation or document ID (`obs_*`, `doc_*`).
   - Every medical assertion must cite a source registered in `knowledge/SOURCES.md` (`src_*`).
4. **Emergency Red-Flag Intercept**:
   - Emergency symptoms (chest pain, shortness of breath, loss of consciousness, stroke signs, severe hemorrhage) must trigger the emergency screen immediately before any LLM inference occurs.
5. **No Cloud PHI**:
   - External cloud LLMs receive only synthetic or Presidio-redacted data.
